# 🧪 Автоматический тестовый вопрос при запуске

**Статус:** ✅ Реализовано  
**Дата:** 2026-04-19

---

## 🎯 Описание

При запуске в debug-режиме можно автоматически отправить тестовый вопрос после загрузки документов. Это ускоряет тестирование функциональности.

---

## 🚀 Способы использования

### **Способ 1: Переменная окружения (рекомендуется)**

```bash
# Вариант 1: Простейший (отправляет "Что такое RAG?" по умолчанию)
export RAG_DEBUG_MODE=true
python app.py --mode ui

# Вариант 2: Свой вопрос через env var
export RAG_TEST_QUESTION="Как работает RAG система?"
export RAG_DEBUG_MODE=true
python app.py --mode ui
```

### **Способ 2: CLI флаг (одна команда)**

```bash
python app.py --mode ui --test-question "Как работает RAG система?"

# С debug-режимом одновременно
export RAG_DEBUG_MODE=true
python app.py --mode ui --test-question "Какие документы загружены?"
```

### **Способ 3: Комбинированный (максимум инструментов)**

```bash
# Все сразу: debug-режим + быстрая модель + тестовый вопрос
export RAG_DEBUG_MODE=true
export RAG_TEST_QUESTION="Расскажи о RAG"
python app.py --mode ui
```

## 🛡️ Защита от дублирования

**Проблема:** При каждом rerun Streamlit не должна отправлять вопрос заново.

**Решение:** Используется `session_state` флаг:

```python
if question_to_auto_send and not st.session_state.get("auto_test_question_sent", False):
    # Отправляем вопрос только один раз
    st.session_state.auto_test_question_sent = True
    # Отправка...
```

**Результат:**
- ✅ При первом запуске: вопрос отправляется
- ✅ При rerun (клик в UI): вопрос НЕ отправляется заново
- ✅ При обновлении страницы: новая сессия → новый вопрос

## 📋 Реализация

### **Файлы изменены:**

#### **1. config.py** (добавлено)
```python
@dataclass
class DebugConfig:
    # ...
    test_question: str = os.getenv("RAG_TEST_QUESTION", "")
```

#### **2. app.py** (добавлено)
```python
parser.add_argument(
    "--test-question",
    type=str,
    help="Автоматически отправить тестовый вопрос"
)

# При запуске:
if args.test_question:
    os.environ["RAG_TEST_QUESTION"] = args.test_question
```

#### **3. streamlit_app.py** (добавлено)
```python
# Инициализация флага в session_state
"auto_test_question_sent": False

# Получение вопроса
test_question = debug_config.test_question or os.getenv("RAG_TEST_QUESTION", "")

# Автоматическая отправка после загрузки документов
if question_to_auto_send and not st.session_state.get("auto_test_question_sent", False):
    st.session_state.auto_test_question_sent = True
    handle_user_query(question_to_auto_send)
```
