## Выявленные проблемы

### 1. ❌ НЕТ НОРМАЛИЗАЦИИ ТЕКСТА ПЕРЕД ЧАНКИРОВАНИЕМ

**Критическая проблема:** Текст из PDF используется **как есть**, без очистки.

#### Цепочка обработки:
```python
# data_loader.py, строка 411-413
loader = PyPDFLoader(str(pdf_path))
documents = loader.load()  # ← БЕЗ ОЧИСТКИ
total_text = "".join(doc.page_content for doc in documents)
```

**Что теряется:**
- Множественные пробелы (2-5 подряд) → не объединяются в один
- Переносы строк внутри слов (`при\nнять` → две части)
- Табуляции и странные whitespace символы
- Артефакты PDF (разделители страниц, колонки)

### 3. ⚠️ TextSplitter работает с нечищенным текстом

**Конфигурация в config.py, строка 172-174:**
```python
chunk_size: int = 500                  # Размер чанка в символах
chunk_overlap: int = 80               # Перекрытие между чанками
chunk_separators: List[str] = ["\n\n", "\n", ".", "!", "?", ",", " ", ""]
```

**Проблема:** 
- Сепаратор `"\n"` разбивает текст по символам переноса
- Если в PDF есть переносы внутри слов, TextSplitter разбивает предложения неправильно
- Множественные пробелы считаются за несколько символов → чанки получаются рваными

**Пример:**
```
Входной текст из PDF:
"Это  первое  предложение.   Второе
предложение здесь."

TextSplitter видит:
- Множественные пробелы = растрата символов
- Неправильный перенос = разбитое слово
- Рваные чанки с потерей контекста
```

## Предложения по улучшению

### ✅ Решение 1: Добавить функцию нормализации текста

**Место:** `src/rag_gigachat/data/data_loader.py` (после импортов)

```python
import re

def normalize_text(text: str) -> str:
    """
    Нормализация текста из PDF для улучшения качества эмбеддингов.
    
    Действия:
    - Удаляет множественные пробелы (2+) → один пробел
    - Удаляет множественные переносы строк → один перевод строки
    - Убирает странные whitespace символы (табуляции, no-break space)
    - Удаляет пустые строки между абзацами (оставляет max 1)
    - Чистит разрывы внутри слов (перенос без дефиса)
    
    Args:
        text: Сырой текст из PDF
        
    Returns:
        Нормализованный текст
    """
    if not text:
        return ""
    
    # 1. Заменяем табуляции и no-break space на обычный пробел
    text = text.replace('\t', ' ').replace('\u00A0', ' ')
    
    # 2. Удаляем множественные пробелы (2+) → один пробел
    text = re.sub(r' {2,}', ' ', text)
    
    # 3. Удаляем странные символы перевода строки (CRLF → LF)
    text = text.replace('\r\n', '\n').replace('\r', '\n')
    
    # 4. Заменяем переносы внутри слов (буква+перевод→буква)
    # Паттерн: строчная буква + перевод строки + строчная буква
    text = re.sub(r'([а-яa-z])\n([а-яa-z])', r'\1\2', text)
    
    # 5. Удаляем множественные переносы строк (3+) → два переноса (абзац)
    text = re.sub(r'\n{3,}', '\n\n', text)
    
    # 6. Удаляем пробелы в начале/конце строк
    text = '\n'.join(line.strip() for line in text.split('\n'))
    
    # 7. Финальный trim
    text = text.strip()
    
    return text
```

### ✅ Решение 4: Улучшить параметры TextSplitter

**Текущая конфигурация (config.py, строка 174):**
```python
chunk_separators: List[str] = ["\n\n", "\n", ".", "!", "?", ",", " ", ""]
```

**Рекомендуемая конфигурация:**
```python
chunk_separators: List[str] = [
    "\n\n",           # Приоритет 1: разделение по абзацам
    "\n",             # Приоритет 2: разделение по строкам (после нормализации они хорошие)
    "(?<=[.!?])\s+",  # Приоритет 3: разделение по точкам (с lookahead для пробела)
    "。",             # Для китайского текста
    ",\s*",           # Разделение по запятым
    " ",              # Разделение по словам
    ""                # Fallback: по символам
]
```

**Почему:** После нормализации переносы будут надёжнее, но лучше использовать regex для точек.

## 📊 Статистика потери данных

**Гипотетический пример:**
```
Исходный PDF (500 символов):
"Первое  предложение.   Второе
предложение  здесь."

После PyPDFLoader (БЕЗ нормализации):
- Множественные пробелы: 4 × " " вместо 1
- Перенос строки в слове: "пред\nложение"
- Полученный чанк 1: "Первое  предложение.   Вто" (потеря контекста)
- Полученный чанк 2: "ое\nпредложение  здесь." (рваный текст)

После нормализации:
- Текст: "Первое предложение. Второе предложение здесь."
- Чанк 1: "Первое предложение." (правильное предложение)
- Чанк 2: "Второе предложение здесь." (полный контекст)

Эмбеддинги:
- Без нормализации: Низкое качество, неправильный контекст
- С нормализацией: Высокое качество, правильная семантика
```
