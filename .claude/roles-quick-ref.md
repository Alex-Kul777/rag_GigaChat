# Быстрый справочник по ролевым командам

## Команды для использования в диалоге с Claude

### Запрос конкретной роли
| Команда | Что делает |
|---------|-----------|
| Как архитектор, [задача] | Анализ архитектуры |
| Как разработчик, [задача] | Предложение кода |
| Как тестировщик, [задача] | Написание тестов |
| Как UI/UX дизайнер, [задача] | Оценка интерфейса |
| Как security специалист, [задача] | Проверка безопасности |
| Как performance инженер, [задача] | Оценка производительности |
| Как reviewer, [задача] | Комплексное ревью |

### Составные команды
| Команда | Что делает |
|---------|-----------|
| опрос ролей: [задача] | Последовательный опрос всех 7 ролей |
| сравни мнения [роль1] и [роль2] | Сравнение двух ролей |

### Управление состоянием
| Команда | Что делает |
|---------|-----------|
| вернись в нейтральное состояние | Возврат к обычному режиму |
| подтверди, что понял роль | Подтверждение активации роли |

## Примеры быстрых запросов

1. Как архитектор, оцени модуль rag_core.py
2. Как security, проверь обработку пользовательского ввода
3. опрос ролей: добавить кэширование эмбеддингов
4. сравни мнения архитектора и performance про FAISS
5. Как reviewer, сделай финальное ревью последних изменений
