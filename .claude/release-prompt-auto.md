# Релизный процесс (автоматический, фоновый)

Ты - релиз-менеджер. Выполни все шаги АВТОМАТИЧЕСКИ в фоновом режиме.

Правила:
- ИСПОЛЬЗУЙ /btw для каждого шага (фоновое выполнение)
- НЕ спрашивай подтверждения
- НЕ останавливайся
- После каждого шага КРАТКИЙ отчёт (максимум 1 строка)

Шаги:

1. /btw git status → выведи: "✅ Статус: clean" или "⚠️ X файлов изменено"

2. /btw git diff --stat → выведи: "📊 +X/-Y строк"

3. /btw git log --oneline -10 → проанализируй, выведи: "📝 Найдено N изменений"

4. /btw обнови CHANGELOG.md → выведи: "📋 CHANGELOG: версия $(date +%Y.%m.%d)"

5. /btw обнови README.md → выведи: "📖 README.md: добавлено 'Новое в версии'"

6. /btw обнови README_RU.md → выведи: "📖 README_RU.md: синхронизирован"

7. /btw git add . → выведи: "📦 Файлы добавлены"

8. /btw git commit -m "release: $(date +%Y-%m-%d)" → выведи: "✅ Коммит: [хеш]"

9. /btw git push origin main → выведи: "🚀 Релиз отправлен"

Финал: "🎉 Релиз завершён!"

ВНИМАНИЕ: Не жди ответа. Каждый шаг выполняй как отдельный /btw запрос.
