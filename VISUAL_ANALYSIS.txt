│ ЭТАП 2: ЧАНКИРОВАНИЕ (TextSplitter.split_documents, config.py:172-174)      │
└─────────────────────────────────────────────────────────────────────────────┘

    TextSplitter видит ГРЯЗНЫЙ текст:
    
    Параметры:
    ├─ chunk_size: 500 символов    ← ВКЛЮЧАЕТ ЛИШНИЕ ПРОБЕЛЫ!
    ├─ chunk_overlap: 80
    └─ separators: ["\n\n", "\n", ".", "!", "?", ",", " ", ""]
    
    Пример разбиения на грязном тексте (500 сим):
    ┌──────────────────────────────────────────────────────────┐
    │ "Первое  предложение.   Второе                           │  ← 500 символов
    │ предложение  здесь.  Третье   предложение.   Четвертое"  │     (с лишними пробелами)
    └──────────────────────────────────────────────────────────┘
                       ↓ TextSplitter разбивает
            ┌──────────────────────┬──────────────────────┐
            │ ЧАНК 1: 500 символов │ ЧАНК 2: 520 символов │
            ├──────────────────────┼──────────────────────┤
            │ "Первое  предложение │ .   Второе           │
            │ .   Второе предложе  │ предложение  здесь   │
            │ ние  здесь.  Трет"   │ .  Третье   предлож" │
            └──────────────────────┴──────────────────────┘
                    ↓                       ↓
            ❌ РВАНЫЙ ЧАНК 1       ❌ РВАНЫЙ ЧАНК 2
                    ↓                       ↓
             Потеря контекста      Неполное предложение


┌─────────────────────────────────────────────────────────────────────────────┐

    FAISS.from_documents(documents, embeddings)
                │
                ├─→ Эмбеддинг чанка 1: "Первое  предложение.   Второе предложе"
                │   └─→ Вектор содержит искаженную семантику (рванный контекст)
                │
                ├─→ Эмбеддинг чанка 2: "ние здесь.   Третье   предложение"
                │   └─→ Вектор не совпадает с поисковым запросом (потеря смысла)
                │
                └─→ Качество поиска: НИЗКОЕ
                    (векторное пространство искажено)

    │ → Вектор запроса совпадает                          │
    │ → Поиск находит документ                            │
    │ → Скор сходства: 0.92 (высокий)                    │
