## 🎯 Проблема (из отладки)

Система RAG теряет качество поиска из-за:
1. ❌ **Грязного текста** из PDF (множественные пробелы, разрывы слов, табуляции)
2. ❌ **Неправильного разбиения** на чанки (regex не учитывает семантику)
3. ❌ **Маленьких чанков** с недостаточным контекстом (<30 токенов)
4. ❌ **Отсутствия поддержки RU+EN** текста одновременно

### ФАЗА 2.6: Фильтрация маленьких чанков ⭐ (30 мин) [НОВОЕ]
**Реализовать функцию для удаления чанков <30 токенов**

```python
def get_token_count(text: str, model: str = "gpt2") -> int:
    """Подсчет количества токенов в тексте"""
    # Используем tiktoken (как в GigaChat)
    # Или approximate: len(text.split()) * 1.3

def filter_short_chunks(documents: List[Document],
                        min_tokens: int = 30) -> List[Document]:
    """Фильтрует чанки с недостаточным контекстом"""
    result = []
    accumulated = None  # Для объединения маленьких чанков
    
    for doc in documents:
        token_count = get_token_count(doc.page_content)
        
        if token_count >= min_tokens:
            # Чанк достаточно большой
            if accumulated:
                # Добавляем накопленный текст
                combined = accumulated + "\n" + doc.page_content
                if get_token_count(combined) <= 500:  # chunk_size
                    doc.page_content = combined
                    accumulated = None
                else:
                    result.append(accumulated)
                    accumulated = None
            
            result.append(doc)
        else:
            # Чанк маленький - накапливаем
            if accumulated:
                accumulated += "\n" + doc.page_content
            else:
                accumulated = doc.page_content
    
    # Добавляем оставшийся накопленный текст
    if accumulated:
        result.append(Document(
            page_content=accumulated,
            metadata={"combined": True}
        ))
    
    logger.info(f"Фильтрация: {len(documents)} → {len(result)} чанков")
    return result
```

**Где вызывать:**
```python
# В TextSplitter.split_documents() после разбиения

chunks = filter_short_chunks(chunks, min_tokens=30)  # ← ДОБАВИТЬ

import tiktoken

def get_token_count(text: str) -> int:
    """Подсчет токенов через tiktoken"""
    encoding = tiktoken.get_encoding("cl100k_base")
    return len(encoding.encode(text))
```

**Вариант 2: Приблизительный подсчет (быстрее)**

def get_token_count(text: str) -> int:
    """Приблизительный подсчет: слова * 1.3"""
    return int(len(text.split()) * 1.3)
